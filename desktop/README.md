# БАС Симулятор — настольная версия (Windows)

Electron-оболочка вокруг симулятора: игра грузится с диска (`app://`), работает без интернета,
просит у системы дискретную видеокарту (`force_high_performance_gpu`) и не отключает WebGL на старых драйверах.

## Готовые файлы
- `BAS-Simulator-Setup-<версия>.exe` — установщик (выбор папки, ярлыки на рабочем столе и в «Пуске»);
- `BAS-Simulator-<версия>-portable.exe` — без установки, запускается сразу.

Подписи кода нет, поэтому Windows SmartScreen при первом запуске покажет «Windows защитила ваш компьютер» →
«Подробнее» → «Выполнить в любом случае».

## Сборка
Из корня репозитория:

```
npm ci
npm run dist:win
```

Файлы появятся в `desktop/release/`. На Linux дополнительно нужен Wine (`wine64` и `wine32:i386`).
Через GitHub: вкладка Actions → «Установщик для Windows» → Run workflow, готовые .exe — в артефактах запуска.

## Управление
F11 — полный экран, Ctrl+Shift+I — инструменты разработчика (для отчётов об ошибках).
RC-пульт подключается по USB как джойстик — настройка во вкладке «Управление».
