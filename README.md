# drone-scoreboard

Initial repository setup for pr-poehali-dev/drone-scoreboard
## Маршрут добра

Командная игра для волонтёров: `public/marshrut-dobra.html` — откройте файл в браузере
(или `/marshrut-dobra.html` на запущенном сайте). Без установки и интернета, кроме шрифтов.

3D-версия: `public/marshrut-dobra-3d.html` — то же самое поле, карточки и правила на объёмном столе
(three.js r128 с CDN): поле можно вращать, кубик бросается прямо на поле.

## Установка на компьютер

Готовые файлы лежат в `installer/dist/`:

- **Windows** — `MarshrutDobra-Setup.exe`. Запустите и нажимайте «Далее». Права администратора не нужны.
  Игра появится на рабочем столе и в меню «Пуск», удаляется через «Приложения» или ярлык «Удалить игру».
  Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»
  (установщик не подписан цифровой подписью).
- **macOS и Linux** — `MarshrutDobra-portable.zip`. Распакуйте, откройте Терминал в папке и выполните `sh install.sh`.
- **Без установки** — распакуйте архив и откройте `Играть.html`.

Игра после установки работает без интернета: 3D-движок и шрифты лежат внутри.

Пересобрать установщики после изменений в игре: `python3 installer/build.py` (для `.exe` нужен `makensis`, пакет `nsis`).
