# drone-scoreboard

Initial repository setup for pr-poehali-dev/drone-scoreboard
## Маршрут добра

Командная игра для волонтёров: `public/marshrut-dobra.html` — откройте файл в браузере
(или `/marshrut-dobra.html` на запущенном сайте). Без установки и интернета, кроме шрифтов.

3D-версия: `public/marshrut-dobra-3d.html` — то же самое поле, карточки и правила на объёмном столе
(three.js r128 с CDN): поле можно вращать, кубик бросается прямо на поле.

## Установка на компьютер

`python3 installer/build.py` собирает в `installer/dist/`:

- **`MarshrutDobra-Setup.exe`** — установщик для Windows 10 и 11. Ставит игру как обычную программу
  (`MarshrutDobra.exe` на Electron): она открывается в своём окне, без браузера и без интернета.
  Права администратора не нужны, ярлыки появятся на рабочем столе и в «Пуске», удаление — через «Приложения».
  Установщик не подписан, поэтому Windows может показать «Система Windows защитила ваш компьютер» —
  нажмите «Подробнее» → «Выполнить в любом случае».
- **`MarshrutDobra-portable.zip`** — тот же установщик плюс `install.sh` для macOS и Linux
  и `Играть.html` для запуска в браузере без установки.

Готовые файлы весят около 110 МБ и в репозиторий не кладутся (у GitHub ограничение 100 МБ на файл).
Для сборки нужны `python3`, `node`/`npm` и `makensis` (пакет `nsis`); Electron скачивается с GitHub один раз
в `installer/.cache` и проверяется по SHA-256.
