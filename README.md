# drone-scoreboard

Initial repository setup for pr-poehali-dev/drone-scoreboard
## Маршрут добра

Командная игра для волонтёров: `public/marshrut-dobra.html` — откройте файл в браузере
(или `/marshrut-dobra.html` на запущенном сайте). Без установки и интернета, кроме шрифтов.

3D-версия: `public/marshrut-dobra-3d.html` — то же самое поле, карточки и правила на объёмном столе
(three.js r128 с CDN): поле можно вращать, кубик бросается прямо на поле.
