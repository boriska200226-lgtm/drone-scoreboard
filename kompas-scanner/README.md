# Скан контура → КОМПАС-3D

Веб-приложение для телефона: фотографируете деталь на листе бумаги известного размера,
получаете точный контур из **отрезков, дуг и окружностей** в DXF (R12, мм, 1:1).
В КОМПАС-3D v24 это обычная редактируемая геометрия: вставляется в эскиз, выдавливается,
на неё можно наложить размеры и ограничения.

## Запуск
- `index.html` — самостоятельная страница без зависимостей: открыть в браузере телефона/ПК
  или выложить на любой статический хостинг (GitHub Pages и т. п.).
- `node build.mjs` — пересобрать `index.html` и `dist/kompas-scan.html` из `app.html` + `core.js`.
- `node test/run.mjs` — проверка точности на синтетических фото с известной геометрией.

## Как это работает
1. Поиск листа (крупнейшая светлая область → четырёхугольник максимальной площади)
   и субпиксельное уточнение кромок по профилям яркости.
2. Гомография «мм листа → пиксели» и ортофото листа 4–12 px/мм.
3. Порог Оцу, морфология, отбор деталей и отверстий. Изолинии (marching squares) по реальной
   яркости у границы дают субпиксельный контур.
4. Коррекция параллакса: по гомографии и фокусному (EXIF / оценка) находится положение камеры,
   контур переносится на плоскость высоты h.
5. Аппроксимация: оптимальное разбиение (динамическое программирование) на отрезки/дуги
   в пределах допуска, уточнение элементов МНК, пересчёт стыков (пересечения, касания скруглений).
   Контур остаётся точно замкнутым.
6. Экспорт DXF R12 (слои CONTOUR и HOLES; начало координат в левом нижнем углу габарита) и SVG.

## Точность (синтетический тест)
Пластина 100×60, R8, Ø20, паз 20×10, камера под наклоном, 12 Мп: ошибка габарита < 0,01 мм,
Ø20,002, R8,00. Толщина 15 мм с коррекцией высоты: ±0,07 мм (без коррекции +3,5 мм).
На реальных фото ожидайте 0,1–0,3 мм. Главные факторы: точность размеров листа, тени,
резкость, съёмка не над деталью.

# 3D-скан → КОМПАС (`index3d.html`)

Захват делается приложением фотограмметрии на Android (KIRI Engine, RealityScan):
вы обходите деталь с телефоном, и оно строит модель. Страница `index3d.html` открывает экспорт
(STL / OBJ / PLY / GLB без Draco) и превращает его в редактируемую основу для КОМПАС.

1. **Ориентация:** главные оси детали → X/Y/Z, низ определяется по площади плоских граней.
   Можно указать основание касанием: нормаль считается по МНК-плоскости области, а не по одному
   треугольнику. Есть отмена.
2. **Масштаб:** по габариту или двум точкам. Затем точное уточнение по размеру аппроксимированного
   сечения (шум скана там усреднён), сверенному со штангенциркулем.
3. **Уступы:** плоские горизонтальные грани находятся автоматически. Для ступенчатой детали строится
   план слоёв (сечение посередине слоя + высота выдавливания). Есть режимы «с шагом» и «вручную»
   для операции «по сечениям».
4. **Экспорт (zip):** DXF каждого сечения в общей системе координат (XY — центр габарита,
   Z — от основания), STL скана в мм и plan.txt с высотами.

`node test/mesh.mjs` — синтетический скан (поворот, масштаб ×0,0123, шум 0,05 мм):
слои 10,002 + 24,999 (истина 10 + 25), пластина 100,00 × 60,04, Ø20,00, трубка Ø40,01 / Ø20,00.
