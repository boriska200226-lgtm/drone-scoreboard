# 3D-модели симулятора

Положите файлы `.glb` (glTF 2.0, можно со сжатием Meshopt) в эту папку и пропишите их в `manifest.json`.
Модели, которых нет в манифесте, симулятор рисует сам.

Роли и параметры:

| Роль      | Что это                             | Параметр размера          |
|-----------|-------------------------------------|---------------------------|
| `house`   | изба/дом (можно несколько вариантов) | `footprint` — длина, м    |
| `person`  | человек (анимация `anim`)            | `height` — рост, м        |
| `van`     | машина МЧС у базы                    | `height`, м               |
| `tractor` | техника у поля                       | `height`, м               |
| `moose`   | лось                                 | `height` в холке, м       |
| `bear`    | медведь                              | `height`, м               |

Необязательно: `rotY` — поворот в градусах, `anim` — имя анимации (`"none"` — без анимации), `credit` — автор и лицензия.

Пример:

```json
{
  "house": [
    { "url": "izba_01.glb", "footprint": 8, "credit": "Автор, CC-BY 4.0, sketchfab.com/..." },
    { "url": "izba_02.glb", "footprint": 9.5 }
  ],
  "van": [{ "url": "uaz_452.glb", "height": 2.3 }]
}
```

Требования: модель стоит на «земле», ориентирована по оси Y вверх, до ~50 тыс. треугольников на дом,
текстуры до 2048 px. Для сжатия: `npx gltf-transform optimize in.glb out.glb --compress meshopt --texture-compress webp`.
